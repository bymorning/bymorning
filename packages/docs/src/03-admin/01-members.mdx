The **Members** page lists everyone who can access the current Workspace. Each row shows **Email**, **Role**, and **Status**.

## Roles

| Role | What you can do on this page |
| --- | --- |
| **Admin** | View members and invite an **Admin** or **Member**. |
| **Member** | View the member list. |

The first member of a newly provisioned Workspace is an **Admin**.

| Status | Meaning |
| --- | --- |
| **Active** | The email belongs to an existing account with Workspace access. |
| **Pending** | The invitation has not been claimed yet. |

## Invite

Admins see **Invite member**. Members do not. The server also rejects invitation requests from members.

1. Select **Invite member**.
2. Enter an **Email** and choose **Member** or **Admin**.
3. Select **Invite member**. The action reads **Inviting…** until the list refreshes.

Invitations currently accept only email addresses ending in `@bymorning.ai`. Other addresses show **Enter a valid email address.**

ByMorning does not send an email notification. Share the application URL with the invited person. They must sign in with the invited email.

An invited person appears as **Pending** until their account claims the invitation during sign-in. Inviting an email that already has an account produces an **Active** membership.

## Limits

The member list is read-only after an invitation. The page does not change an existing member's role or remove a member.
