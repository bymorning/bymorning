Start a Session to give an Agent a prompt inside a Project. The Project supplies the Session's files and groups it in the sidebar.

## Start

1. Select **New Session** in the sidebar or **New session** on **Overview**. ByMorning uses the current Project. Open the Project picker to choose another Project or **Create Project**.
2. Type `@` to search Skills, Agents, and up to ten matching Project files. You can also open **Add to prompt** and choose **Context**.
3. To upload files, open **Add to prompt** and choose **Images and files**. Each successful upload is stored on the Project under its filename and added as a Project-file reference.
4. Choose an **Agent** and **Model** below the composer. If the Model offers variants, choose a **Variant** or keep **Default**. Changing the Model keeps the current variant only when the new Model supports it.
5. Enter a message and submit. ByMorning creates the Session, opens its transcript, and starts the selected Agent and Model.

An Agent and Model are required. An attachment can be the entire prompt after it finishes uploading.

## Drafts

The new Session stays as a browser-local editor while you compose it and survives a reload. Attachment cards are not restored after a reload, but uploaded files remain in the Project.

Failed uploads stay marked **Upload failed** and are not submitted. The **Commands** menu has no commands until you enter an existing Session.

Continue with [Sessions](/agent/sessions) to read the transcript and control an active run.
