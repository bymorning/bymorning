Skills give Agents reusable instructions for a specific kind of work. The **Skills** page lists the Skills available in the current Workspace.

## Browse

Open **Workspace** in the sidebar, then select **Skills**. Select a row to open its details.

Each Skill shows:

- name and ID
- description
- rendered instructions

If Skills cannot load, select **Retry**. An empty Workspace shows **No skills yet.**

## Use

Type `@` in the Session composer and choose a Skill from the **Skills** group. Search matches its ID, name, or description. ByMorning inserts the Skill reference into your prompt, and the Agent can load those instructions during the run.

See [Start a Session](/agent/start-a-session) for the composer.

## Limits

Skills supplied by a Plugin appear in the list and Session picker but cannot be edited or deleted from this page. Change them where the Plugin declares them.
