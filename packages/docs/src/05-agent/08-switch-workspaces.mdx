Switch Workspaces from the account menu. The active Workspace controls which Projects, Sessions, Skills, and configuration you see.

## Switch

1. Select your account at the bottom of the sidebar.
2. Select **Switch workspace**.
3. Search by name and select a result. The current Workspace is marked **Current**.

Use the arrow keys and Enter to choose a result. Selecting the current Workspace closes the switcher.

Projects and Sessions do not carry across Workspaces. After switching, choose a Project before you [start a Session](/agent/start-a-session).
