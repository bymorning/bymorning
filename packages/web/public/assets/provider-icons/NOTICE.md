# Provider icon assets

The generated dot-named SVG files in this directory are sanitized copies from
[`anomalyco/models.dev`](https://github.com/anomalyco/models.dev) at pinned Git
commit `c00c192726b4059d4fa8f7e5cf4e4140b5993e7a`. models.dev is licensed under the
MIT License.

The complete upstream path and raw SHA-256 manifest is
`packages/models/source/models-dev/pin.json`; raw source files are cached under
`packages/models/source/models-dev/cache/icons/`. The generated filename hash
identifies the sanitized output. Providers with no upstream logo, or whose SVG
does not pass the repository's strict sanitizer, intentionally use the generic
fallback.

Provider names and logos may be trademarks of their respective owners. Their
inclusion identifies supported providers and does not imply ownership by
Bymorning.
